Готово
J.A.R.V.I.S. Remote — только для Android, в домашней сети Wi-Fi. «Включить ПК» будит его из сна (из выключения — только по кабелю). Удерживайте круг JARVIS, чтобы сказать команду; короткое касание — набрать её на клавиатуре. Ctrl, Win, Alt, Shift слева можно зажимать в любых сочетаниях и нажимать букву другим пальцем; касание — для следующей клавиши, двойное — закрепить. Тачпад: три пальца влево/вправо — окна, вверх — все окна, вниз — рабочий стол.
